### *Templating*

Helm usa variabili per generare YAML dinamico.

- `.Values` legge i valori da `values.yaml`
- `.Release.Name` usa il nome della release
- la stessa chart puo` essere riusata in ambienti diversi

### *Debugging*

<Steps>
1. Usa `helm lint` per controllare la chart.
2. Usa `helm install --debug --dry-run` per simulare l'installazione.
3. Controlla i manifest generati prima di applicarli al cluster.
</Steps>


### *Versioning e rollback*

- ogni `helm upgrade` crea una nuova revisione
- puoi vedere la cronologia delle modifiche
- puoi tornare a una revisione precedente con `helm rollback`

### *Sintesi*

| Concetto | Descrizione | Analogia |
| --- | --- | --- |
| `Chart` | Pacchetto riutilizzabile | Ricetta |
| `Values` | Parametri configurabili | Ingredienti |
| `Release` | Istanza installata nel cluster | Piatto servito |
| `Revision` | Storico delle modifiche | Versioni |
