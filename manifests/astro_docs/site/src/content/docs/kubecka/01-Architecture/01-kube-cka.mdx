#### Componenti del Control Plane

| Componente | Funzione |
| --- | --- |
| API Server | Espone e gestisce le richieste Kubernetes |
| ETCD | Salva lo stato del cluster |
| Scheduler | Assegna i Pod ai nodi |
| Controller Manager | Controlla e corregge lo stato del cluster |

#### Componenti del Worker Node

| Componente | Funzione |
| --- | --- |
| Kubelet | Esegue e monitora i Pod sul nodo |
| Kube Proxy | Gestisce il traffico di rete dei Service |
| Container Runtime | Avvia ed esegue i container |
