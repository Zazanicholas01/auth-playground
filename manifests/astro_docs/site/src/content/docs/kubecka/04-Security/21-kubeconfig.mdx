**`Kubeconfig`** è il file che `kubectl` usa per sapere a quale cluster connettersi e con quali credenziali.

### *Struttura principale*

<CardGrid>
  <Card title="Clusters" icon="document">
    Contiene endpoint dell'`API Server` e certificati della `CA`.
  </Card>

  <Card title="Users" icon="information">
    Contiene i certificati dell'utente usati per autenticarsi.
  </Card>

  <Card title="Contexts" icon="list-format">
    Collega utente, cluster e namespace predefinito.
  </Card>
</CardGrid>

### *Come funziona*

<Steps>
1. `kubectl` legge il file `Kubeconfig`.
2. Seleziona il `context` attivo.
3. Dal `context` ricava `cluster`, `user` e namespace.
4. Usa queste informazioni per parlare con l'`API Server`.
</Steps>

### *Gestione dei contesti*

| Comando | Scopo |
| --- | --- |
| `kubectl config get-contexts` | Elenca i contesti |
| `kubectl config use-context <nome>` | Cambia contesto |
| `kubectl config current-context` | Mostra il contesto attivo |
