This section covers `Microsoft Sentinel`, the cloud-native SIEM and SOAR platform in Azure.

### *Microsoft Sentinel*

`Microsoft Sentinel` is a cloud-native security operations platform.

It combines:

- `SIEM` (`Security Information and Event Management`)
- `SOAR` (`Security Orchestration, Automation, and Response`)

Its role is to collect security data, detect threats, investigate incidents, and help automate responses.

<Aside type="note">
If `Defender for Cloud` focuses on improving security posture and workload protection, `Microsoft Sentinel` focuses on security operations and incident response.
</Aside>

### *What Sentinel Does*

### *How It Works*

<Steps>
1. Connect data sources to `Microsoft Sentinel`.
2. Logs are ingested into the monitoring and analytics platform.
3. Analytics rules detect suspicious behavior.
4. Related alerts are grouped into incidents.
5. Security teams investigate and optionally trigger automated responses.
</Steps>

### *Common Data Sources*

Sentinel can ingest data from many sources, such as:

- Azure resources
- Microsoft 365
- Microsoft Entra ID
- firewalls and appliances
- on-premises servers
- third-party security tools

This makes it a central point for security monitoring across environments.

### *Key Capabilities*

| Capability | Purpose |
| --- | --- |
| Analytics Rules | Detect suspicious patterns and generate alerts |
| Incidents | Group related alerts into one investigation case |
| Workbooks | Visualize security data and trends |
| Hunting Queries | Search for suspicious activity using `KQL` |
| Playbooks | Automate response actions |

### *Sentinel Vs. Defender For Cloud*

| Service | Best For |
| --- | --- |
| `Microsoft Defender for Cloud` | Security posture management and workload protection |
| `Microsoft Sentinel` | Security operations, incident detection, and response |

They work well together:

- `Defender for Cloud` improves security posture and detects workload threats
- `Sentinel` collects and correlates security signals across the wider environment

### *Summary*

- `Microsoft Sentinel` is Azure's cloud-native `SIEM` and `SOAR` platform
- It collects, analyzes, and correlates security data
- It helps detect, investigate, and respond to incidents
- It supports automation through playbooks
- It complements `Defender for Cloud` in the Azure security stack
