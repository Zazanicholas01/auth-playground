This section covers `Azure Artifacts`, the Azure DevOps service used to manage packages and reusable software artifacts.

### *Azure Artifacts*

`Azure Artifacts` is the package management service inside Azure DevOps.

It allows teams to create, host, and share packages such as:

- NuGet packages
- npm packages
- Maven packages
- Python packages
- universal packages

It is useful when software teams want controlled internal package feeds for reusable libraries and build outputs.

<Aside type="note">
`Azure Artifacts` helps teams treat packages as managed assets instead of passing files around manually between builds and projects.
</Aside>

### *How It Works*

<Steps>
1. A package is built through a development or CI process.
2. The package is published to an `Azure Artifacts` feed.
3. Other projects or pipelines connect to that feed.
4. Teams consume the package as a managed dependency.
5. New versions are published and tracked over time.
</Steps>
