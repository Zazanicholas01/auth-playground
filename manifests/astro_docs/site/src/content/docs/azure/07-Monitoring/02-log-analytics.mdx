This section covers `Log Analytics`, the Azure service used to store, query, and analyze log data.

### *Log Analytics*

`Log Analytics` is the log data analysis engine inside the Azure monitoring ecosystem.

While `Azure Monitor` is the broader observability platform, `Log Analytics` is the part used to work directly with collected logs.

It is built for:

- troubleshooting
- investigation
- operational analysis
- security review
- historical querying

<Aside type="note">
If metrics answer "What is happening right now?", logs often answer "Why did it happen?"
</Aside>

### *Log Analytics Workspace*

A `Log Analytics Workspace` is the main container for log data.

Azure resources, agents, and services send diagnostic data into the workspace, where it can be queried and analyzed.

A workspace acts as the central location for:

- collected logs
- query history
- saved searches
- monitoring integrations

### *KQL Queries*

Log Analytics uses `Kusto Query Language (KQL)` to search and analyze data.

With `KQL`, you can:

- filter records
- sort results
- aggregate values
- correlate events
- build operational queries

This makes it one of the most powerful tools for Azure diagnostics and investigation.

### *Typical Flow*

<Steps>
1. Azure resources send logs into a `Log Analytics Workspace`.
2. The logs are stored and indexed.
3. Engineers use `KQL` queries to search or analyze the data.
4. Queries can power dashboards, workbooks, or alerts.
5. Teams investigate incidents or monitor trends over time.
</Steps>

### *Log Analytics Vs. Metrics*

| Type | Best For |
| --- | --- |
| Metrics | Fast numerical monitoring and threshold alerts |
| Logs | Detailed event records, analysis, and troubleshooting |

Metrics are lighter and faster for real-time monitoring.

Logs are richer and better for deeper investigation.

### *Summary*

- `Log Analytics` is the log analysis engine of Azure monitoring
- A `Log Analytics Workspace` stores and organizes collected logs
- `KQL` is used to query and analyze the data
- It is essential for troubleshooting and operational investigation
- It complements metrics-based monitoring in `Azure Monitor`
