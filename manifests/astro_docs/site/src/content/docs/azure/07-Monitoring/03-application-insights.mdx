This section covers `Application Insights`, the Azure service used for application performance monitoring.

### *Application Insights*

`Application Insights` is the Azure service used to monitor the behavior and performance of applications.

While `Azure Monitor` gives broad observability across Azure resources, `Application Insights` focuses specifically on the application layer.

It helps you understand:

- request performance
- failures and exceptions
- dependency calls
- user behavior
- application availability

<Aside type="note">
`Application Insights` is one of the most useful tools for understanding not just whether an application is running, but how well it is actually behaving for users.
</Aside>

### *How It Works*

<Steps>
1. Instrument the application with the `Application Insights` SDK or Azure integration.
2. The application sends telemetry to Azure.
3. Azure stores and correlates requests, dependencies, exceptions, and traces.
4. Teams analyze the data through dashboards, investigations, and queries.
5. Alerts and reports can be built on top of the telemetry.
</Steps>

### *Application Insights Vs. Log Analytics*

| Service | Best For |
| --- | --- |
| `Application Insights` | Application behavior, performance, and request tracing |
| `Log Analytics` | Broader operational and infrastructure log analysis |

`Application Insights` is application-focused.

`Log Analytics` is broader and often used across many Azure services.

### *End-To-End Monitoring*

Application Insights is especially valuable because it can correlate different parts of one user request.

For example, it can help track:

- the incoming web request
- the API call
- the SQL dependency
- the error or timeout that happened later

This makes troubleshooting much easier in modern distributed systems.

### *Summary*

- `Application Insights` is Azure's application performance monitoring service
- It tracks requests, dependencies, exceptions, and availability
- It helps identify slow performance and application failures
- It is especially useful for web apps, APIs, and distributed systems
- It complements `Azure Monitor` and `Log Analytics` in the broader monitoring stack
