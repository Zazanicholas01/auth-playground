This section covers `Azure Digital Twins`, the Azure service used to model real-world environments and relationships in a digital form.

### *Azure Digital Twins*

`Azure Digital Twins` is a platform for creating digital models of physical environments, assets, and systems.

Instead of only collecting raw telemetry, it helps represent:

- buildings
- rooms
- devices
- machines
- people
- relationships between those entities

This allows applications to understand not only device data, but also the context around that data.

<Aside type="note">
`Azure Digital Twins` is useful when the value is not only in the sensor reading itself, but in how that reading relates to spaces, equipment, and business structures.
</Aside>

### *What A Digital Twin Represents*

A digital twin is a software model of a real-world entity.

Examples:

- one room in a building
- one HVAC unit
- one production line
- one warehouse area

Each twin can store properties, state, and relationships to other twins.

### *Typical Flow*

<Steps>
1. Define models for the types of entities in the environment.
2. Create twins based on those models.
3. Create relationships between the twins.
4. Ingest telemetry or events from connected systems.
5. Query the graph to understand the state of the environment.
</Steps>

### *Azure Digital Twins Vs. IoT Hub*

| Service | Best For |
| --- | --- |
| `Azure IoT Hub` | Device communication and telemetry exchange |
| `Azure Digital Twins` | Modeling environments, assets, and relationships |

`IoT Hub` focuses on device communication.

`Azure Digital Twins` focuses on contextual modeling and connected entity relationships.

### *Summary*

- `Azure Digital Twins` creates digital models of real-world environments
- It represents entities, properties, and relationships as a graph
- It adds context to telemetry and operational data
- It is useful for smart buildings, industrial systems, and connected environments
- It complements IoT services by modeling the world around the devices
